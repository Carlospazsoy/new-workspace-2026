# Estudio Web

Un cuaderno interactivo para aprender los fundamentos de HTML, CSS y JavaScript con ejemplos breves y pequeñas prácticas.

## Empezar

Abre `index.html` en un navegador. No hace falta instalar nada ni tener conexión a internet.

## Recorrido

- **HTML:** estructura, semántica y formularios.
- **CSS:** selectores, Flexbox y Grid.
- **JavaScript:** variables, DOM y eventos.

Cada lección incluye una idea clave, un ejemplo de código, un reto y una pregunta rápida. Puedes filtrar las materias, copiar los ejemplos y marcar lecciones como completadas. El progreso se guarda en el almacenamiento local del navegador.

## Archivos

- `index.html`: estructura y navegación del curso.
- `styles.css`: estilos adaptables a móvil y escritorio.
- `script.js`: contenido de las lecciones, cuestionarios y progreso.

## Personalizar

Edita el arreglo `lessons` en `script.js` para agregar o cambiar lecciones. Cada lección define su materia, explicación, código, reto y pregunta. Mantén los identificadores únicos para conservar correctamente el progreso.
